## AI Usage

### Tools Used and Their Purpose

- **Claude.ai:** Reviewed project documentation and the design process. It also helped reorganize development slices to support the project's vertical-slicing approach.
- **ChatGPT:** Helped me understand technical concepts, evaluate alternative approaches, and make better design and implementation decisions.
- **Antigravity (powered by Gemini):** Used for code analysis, test generation, and final code cleanup.

AI suggestions were not always suitable for the project's actual requirements or existing architecture. Rather than accepting suggestions blindly, I compared them with the project requirements and existing code, verified the proposed approaches, and made the final decisions myself.
